Project Title
Waze User Churn Prediction & Behavioral Driver Analysis Using Binomial Logistic Regression
Project Overview
This project analyzes user engagement and driving behavior data from 14,299 active Waze users to uncover the primary drivers of customer attrition (17.7% churned vs. 82.3% retained). Following the PACE (Plan, Analyze, Construct, Execute) data analytics workflow, a binomial logistic regression model was developed to quantify how app usage frequency, driving distance, user tenure, and device platform influence retention, providing Waze leadership with actionable, data-driven retention strategies.
Business Understanding
 * Business Problem: Retaining active users is critical for Waze’s crowd-sourced navigation ecosystem, as real-time traffic and hazard accuracy depend on continuous community participation. High user churn directly erodes network value and long-term platform growth.
 * Project Objective: Identify statistically significant behavioral predictors of user churn and evaluate whether a baseline binomial logistic regression model can reliably flag at-risk users before they abandon the app.
 * Stakeholder Value: Analytical insights enable product and growth teams to design targeted onboarding interventions, streak incentives, and tailored navigation features for high-risk user segments.
Data Understanding
 * Dataset Scope & Cleaning: From an initial dataset of 14,999 records, 700 rows with missing churn labels (label) were removed, leaving 14,299 complete user records (82.3% retained, 17.7% churned).
 * Variables & Feature Engineering: The data captures monthly app sessions, drives, total kilometers driven, driving duration, active app days (activity_days), user tenure (n_days_after_onboarding), and device type (iPhone vs. Android). Engineered behavioral metrics—most notably km_per_driving_day—were created to measure driving intensity per active day.
 * Exploratory Insights: Retained users open the app significantly more days per month than churned users. Conversely, users who drive unusually long distances on infrequent driving days exhibit substantially higher churn rates, while device type (iPhone vs. Android) shows negligible impact on churn behavior.
Modeling and Evolution
 * Baseline Model (Binomial Logistic Regression): After handling extreme outliers and verifying the absence of severe multicollinearity among predictor variables, a binomial logistic regression model was trained to predict binary churn status and interpret feature log-odds.
 * Model Evaluation: On the held-out test set, the model achieved 82.3% overall accuracy and ~52% precision, but recorded only ~9.4% recall (0.16 F1-score). Because the dataset is heavily imbalanced toward retained users (82.3%), the linear decision boundary misses a large share of actual churners.
 * Key Predictive Drivers: activity_days emerged as the strongest negative predictor of churn (more active days per month markedly reduce churn odds), whereas km_per_driving_day was the strongest positive predictor of churn, alongside shorter user tenure (n_days_after_onboarding).
 * Model Evolution (Next Steps): While binomial logistic regression excels at explaining behavioral churn drivers, its low recall limits its effectiveness as a standalone predictive classifier. The next phase of model evolution transitions to non-linear, tree-based ensemble algorithms (Random Forest and XGBoost), incorporates class-rebalancing techniques, and integrates richer behavioral telemetry such as app crash logs, traffic-alert interactions, and route ETA accuracy.
Conclusion
Monthly engagement frequency—rather than hardware platform—is the primary determinant of user retention on Waze. Habitual daily or weekly commuters (high activity_days) remain loyal, whereas newer users and infrequent, long-distance drivers (high km_per_driving_day) face the highest risk of churning. By pairing early-tenure onboarding prompts and activity streak rewards with tailored long-trip route features—and evolving the modeling pipeline from logistic regression to tuned Random Forest and XGBoost classifiers—Waze can proactively identify at-risk users and measurably reduce overall churn.
